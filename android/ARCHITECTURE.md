# 架构原则

本文规定模块边界、依赖方向、状态、数据、安全和验证原则。接口细节见 [LAN Share 协议](core/lan-share/PROTOCOL.md)，本地命令见[开发验证指南](DEVELOPMENT.md)。

## 模块与依赖

```text
:app ───────────────> :core:domain
  ├────────────────> :core:data ─────────> :core:domain
  └────────────────> :core:lan-share ────> :core:domain
```

依赖只能按箭头方向流动，不得反向依赖或形成循环。

| 模块 | 职责 |
| --- | --- |
| `:core:domain` | 定义业务数据、规则和接口；不依赖 Android、Compose、存储框架或条码库。 |
| `:core:data` | 实现数据接口，负责本地存储、迁移和平台能力接入；不依赖 UI 或 `:app`。 |
| `:core:lan-share` | 实现局域网服务、客户端和传输协议；通过 Domain 接口与应用协作，不依赖 UI、`:core:data` 或 `:app`。 |
| `:app` | 组合各模块，负责页面、应用流程、Android 交互和依赖注入。 |

`:core:domain` 是依赖核心。插件和库版本由 Version Catalog 管理。UI 与 Presentation 目前都属于 `:app`，包名不是独立模块。

## 分层职责

- **Domain**：描述业务规则和接口，不保存页面状态或处理 Android 生命周期。
- **Data / LAN Share**：实现接口，隔离数据库、网络和平台细节。
- **Presentation**：组织业务流程、维护页面状态并发送一次性事件；不能依赖 Compose/UI。页面退出不能取消必须完成的数据写入。
- **UI**：按状态显示页面，把操作交给 Presentation；不直接访问 DAO、文件系统或网络实现。Feature UI 接收显示状态或只读数据，通过回调发送用户操作；路由负责连接界面和状态层。
- **视觉组件**：动画统一放在 `ui.animation`，玻璃材质放在 `ui.component.glass`。它们不持有业务状态，也不依赖应用装配层。普通内容卡片保持实色；视觉效果不能改变点击范围、焦点或业务状态。
- **材质与无障碍**：玻璃控件复用统一实现和预设，不在页面复制 shader。效果不可用时清晰降级，不能隐藏操作或状态。视觉是否达标要用真机确认。
- **应用装配**：Android 系统 API 与依赖注入绑定放在 `:app`；只有明确需要独立复用时才下沉到 Core 模块。
- **条码库**：ZXing 由 Data 中的平台适配器封装。Presentation 通过接口请求编码或解码，UI 不直接依赖 ZXing。更换条码库不能要求迁移用户数据。

## 状态、事件与导航

- 持续展示的状态使用 `StateFlow` 等状态容器；它不等于持久化，也不保证进程重启后自动恢复。
- 需要可靠送达的单次操作（如系统请求、下载完成）使用 `Channel`。允许未订阅者错过的广播才使用 `SharedFlow`。
- 当前页面由统一导航状态管理；页面间传递稳定 ID 或不可变参数，不传 DAO、`Context` 或可变数据库实体。
- 进程恢复只保存轻量标识；长期数据进持久化层，不把位图等大对象放入 Saved State。

## 持久化

- 数据模块是已保存数据的权威来源，页面状态只服务当前交互。
- 正式 ID 在数据事务中生成；收藏标记及其关联要在同一事务保持一致。
- 写入顺序、失败恢复和旧数据迁移由数据层负责，不能依赖某个 ViewModel 一直存活。
- 临时传输文件与用户数据分开存放，不能进入用户备份；存储位置变化时同步检查清理规则。

## LAN Share 安全与生命周期

- 用户主动开启分享；Android App 创建服务，浏览器可作为无需安装 App 的加入端。
- 同一 Wi-Fi 只代表网络可达，不代表身份可信。认证、加密和访问范围以 [协议安全模型](core/lan-share/PROTOCOL.md#安全模型) 为准，界面说明必须与实际一致。
- 服务只使用当前 Wi-Fi 地址。端口和路径用于定位，不是身份凭据。
- 离开文件传输页时关闭服务并清理会话文件；进入后台不主动关闭。进程被强制结束时清理不保证完成，下次启动需处理遗留临时文件。
- 校验文件名、请求和会话范围，防止越权访问与路径穿越。预览文件不能改写原文件。

## 验证与文档同步

- 各模块测试业务规则、存储和协议；架构测试检查依赖方向。
- Wi-Fi、Android 生命周期和系统选择器需真机验证；编译或单元测试不能代替设备检查。
- 涉及模块、状态、数据、安全边界的改动要同步更新本文；接口改动更新协议文档，命令和操作更新开发指南。
