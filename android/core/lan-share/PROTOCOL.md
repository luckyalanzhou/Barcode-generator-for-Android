# LAN Share 协议说明

本文记录 `:core:lan-share` 当前 HTTP 与 WebSocket 接口，供 App、浏览器页面和协议测试共同参考。它描述可变的实现协议，不替代 [项目架构原则](../../ARCHITECTURE.md)。修改接口或消息格式时，应同步更新本文和对应测试。

## 连接模型

- Android App 创建分享房间并启动 HTTP/WebSocket 服务；加入端通过浏览器访问根页面。当前不需要安装加入端 App，也没有登录、令牌、访问码或 HTTPS 加密。
- 服务地址使用当前 Wi-Fi 子网 IPv4 与随机端口，端口范围为 `18080–28080`，并避免紧接着复用上次使用的端口。随机端口仅用于选择监听端口，不是访问凭据。
- App 校验手动输入或扫码得到的地址是否位于当前路由器子网；服务只从当前 Wi-Fi 网络选择地址，不把 VPN、蜂窝或公网作为加入入口。
- 会话只在服务进程内有效。离开 App 文件传输页时停止服务并清理本次分享文件；App 进入后台不会主动关闭。进程被系统强制结束时，不保证清理缓存与临时文件。

## 安全模型

- 同一 Wi-Fi 局域网仅作为网络可达范围，不代表设备身份可信；当前不提供身份认证、访问令牌、访问码或端到端加密。
- 能访问当前分享地址的同网设备可以打开页面并参与文件/消息传输；二维码与 IP/端口用于便捷定位服务，不构成授权凭据。
- 服务只选择当前 Wi-Fi 子网地址，不将蜂窝、VPN 或公网地址作为分享入口。App UI 应明确提示同 Wi-Fi 下可访问。
- 服务端仍须校验文件名、请求内容和会话文件范围，避免路径穿越或访问非会话文件；安全输入校验不等同于身份认证。

## HTTP 接口

| 方法与路径 | 用途 | 当前行为 |
| --- | --- | --- |
| `GET /` | 获取内嵌浏览器页面 | 返回当前版本的 HTML/CSS/JavaScript。 |
| `GET /api/files` | 获取文件清单 | 返回 JSON 数组；每项含 `id`、`name`、`size`、`modifiedAt`、`sender`、`mimeType`。 |
| `PUT /upload?name=...&client=...&transfer=...` | 上传原文件 | 请求体按原始字节保存，不做图片压缩或内容转换；成功响应正文为服务端文件 ID。`transfer` 可选。 |
| `GET /dl/{id}` | 下载原文件 | 返回会话文件原字节；预览生成不改写原件。 |
| `GET /api/preview/{id}` | 取得浏览器显示用图片预览 | 支持的格式按需生成浏览器可显示的预览；无法预览时返回 `406`，原文件仍可通过下载接口取得。 |

上传请求使用 `Content-Type` 表示媒体类型。固定长度请求可由 `Content-Length` 或 `X-File-Size` 声明长度；浏览器使用 HTTP chunked body 时须提供 `X-File-Size`。服务端以固定缓冲区流式写入临时文件，检查实际字节数与声明一致后才发布文件，不会将整个文件载入内存。文件名经过清理并限制长度；单文件上限为 10 GiB，单房间累计上限为 100 GiB。

原始文件和 MIME 类型在文件清单及下载响应中保持对应关系。服务端只允许访问分享目录中的已完成文件，拒绝临时上传文件、路径穿越和不存在的文件。浏览器预览缓存与原始文件分开保存。

## WebSocket 消息

浏览器连接 `ws://{host}:{port}/ws?client={clientId}`。连接成功后应发送文本帧 `sync` 获取当前快照。浏览器断线后按当前页面逻辑每秒重连。

快照的 JSON 结构：

```json
{
  "type": "snapshot",
  "files": [{"id": "...", "name": "...", "size": 123, "modifiedAt": 0, "sender": "...", "mimeType": "..."}],
  "messages": [{"id": "...", "text": "...", "sender": "...", "createdAt": 0}]
}
```

服务端到客户端的事件：

| `type` | 字段 | 含义 |
| --- | --- | --- |
| `snapshot` | `files`, `messages` | 当前文件与文字消息快照。 |
| `message` | `message` | 新文字消息。 |
| `files` | `file`, 可选 `transferId` | 新上传的文件；`transferId` 用于对应浏览器本地上传进度项。 |
| `error` | `message` | 消息校验失败等可显示错误。 |

浏览器发送文字消息：

```json
{"type":"message","text":"你好"}
```

文字为空或 UTF-8 内容超过 64 KiB 时拒绝。App 与浏览器两端的文字消息进入当前进程内的共享会话列表，最多保留 100 条；服务结束后不持久化。

连接状态由 WebSocket 建立与断开事件驱动。文件状态通过 WebSocket 通知；不依赖周期轮询。浏览器新连接或重连后以 `sync` 请求快照，客户端按 ID 合并以避免重复显示。

## 验证范围

LAN Share 模块测试覆盖固定长度与 chunked 原始字节上传、文件下载完整性、无凭据访问行为、WebSocket 握手和会话状态，以及浏览器页面关键脚本结构。真机 Wi-Fi 路由、Android 生命周期和不同浏览器选择器行为仍需设备手动验证；详见 [开发验证指南](../../DEVELOPMENT.md)。
